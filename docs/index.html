03 / SOURCE TO DATABASE

Traceable inputs.
Verified output.

An hourly GitHub Actions workflow mirrors FireHOL, builds unpublished snapshots and publishes both validated downloads.

01

Mirror the upstream commit

main is an exact commit-level mirror of FireHOL's master. The generator checks out the verified immutable SHA. Pipeline code lives on the default mmdb-pipeline branch.

SOURCE
02

Parse in parallel

Rayon parses .ipset and .netset files recursively. *_country directories, hidden directories and symlinks are excluded. Bare addresses become /32 or /128.

RUST
03

Preserve the contributions

Batched external sorting and explicit ancestor propagation retain overlapping sources. A single libmaxminddb-rs writer uses MergeStrategy::DeepMerge with aligned arrays and duplicates.

MERGE
04

Verify, compress and publish

Rust and independent MaxMind readers check the database and source timestamp. The gzip-9 archive passes a CRC and SHA-256 round trip. Both files are confirmed in the new published release before the previous release is deleted. The stable tag is then reassigned to the replacement.

RELEASE

Retries that follow publication

An unchanged source skips compilation only when both assets exist and publication is complete. Missing assets or a pending replacement trigger another build, including a failed forced rebuild of the same commit. Interrupted publication or tag handover resumes on the next run.

Measured on a real snapshot

The 05 Oct 2026 snapshot passed 866 independent lookups. The original production generation took 4.77 seconds with 905,268 KiB peak resident memory. Measurements depend on the runner and input data.

The final writer trie is in memory. Total memory grows with distinct prefixes and metadata combinations.

04 / RECORD PROVENANCE

Every source.
Kept in context.

Record fields are parallel arrays. Values at the same index belong to the same contribution, including repeated sources.

Record fields
FieldMeaning
filesContributing source file names
categoriesCanonical categories such as malware, abuse, botnet and spam
maintainersSource maintainer names
maintainer_urlsMaintainer website URLs
source_urlsOriginal feed URLs
source_file_datesSource header dates; recognized UTC dates normalized to ISO 8601
versionsSource header version values

Alignment is part of the format

Missing optional metadata uses an empty string. Duplicates remain in place, and update frequency is never stored. Array ordering is deterministic.

Global MMDB metadata

database_type: firehol-blocklist-ipsets
ip_version: 6 (IPv4 + IPv6)
languages: ["en"]
binary format: 2.0

Node count and record size are computed by the writer. build_epoch follows the source commit's committer date.
